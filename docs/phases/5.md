# Phase 5: Stripe payments
**Model:** Sonnet 5.5 / High. **Branch:** `phase-5-payments`
**Needs:** STRIPE_* in launch.env. Blank → skip the whole phase and say so in the report.

## Read
The storefront's existing Stripe integration (find it with `grep -ril stripe storefront/src --include=*.tsx -l | head`),
plus the Spree payment-method docs or source for the Stripe gateway.

## Do
1. Create the Stripe payment method via the Admin API (`scripts/setup-payments.ts`, idempotent), in test mode.
2. Enable the storefront flow (env + config). No Stripe secret may reach the client.
3. Playwright: checkout with 4242 4242 4242 4242, with 3DS 4000 0027 6000 3184, and with a decline (4000 0000 0000 0002).
4. On the completed order, assert the tax lines match Phase 2 for that province and the welcome discount applies.

## Accept
3 card scenarios pass, the order emails are generated, and the totals reconcile.
