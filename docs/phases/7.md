# Phase 7: Compliance features
**Model:** Sonnet 5.5 / Medium. **Branch:** `phase-7-compliance`

## Read
`launch.env` (WELCOME_EMAIL_REQUIRES_OPT_IN, BUSINESS_*, SUPPORT_EMAIL),
`storefront/src/lib/vantage/welcome-discount.ts`, `storefront/src/components/auth/GoogleSignIn.tsx`,
the account register page, `storefront/src/lib/emails/`.

## Do
1. CASL: an unticked "Email me offers" checkbox on register, and an equivalent one-tap prompt after Google sign-up.
   Store the consent in customer metadata: `{marketing_opt_in, at, source, wording}`. If
   WELCOME_EMAIL_REQUIRES_OPT_IN=yes, still issue the coupon and show it on screen, but email it only after opt-in.
   Commercial emails carry the sender ID (BUSINESS_*) and a working unsubscribe link.
2. Legal pages: privacy (PIPEDA + Quebec Law 25), terms, shipping & returns. Draft with
   `pnpm llm legal` (local model), then review. Every page has a "DRAFT, needs lawyer review" banner.
3. A consent banner: no non-essential script (GTM, analytics) loads before consent.
4. NPN guard: supplement-category products can't go `active` without an NPN. Choose the least invasive
   mechanism (a Rails validation in backend/, or a pre-publish check script) and document it.

## Accept
Opt-in honoured both ways (tests), consent stored, unsubscribe works, legal pages live with the banner,
no tag before consent (a test), and the NPN guard is tested.
